# Anita Enterprises CRM: 5-minute demo

**Pitch line:** "Never miss a lead, an enquiry or a follow-up."
Before you start: Settings → *Reset demo data*. Open the app in two windows if you can: one on a phone-width window (staff), one on desktop (owner).

| Min | Do this | Say this |
|---|---|---|
| 0:00 | Login screen → tap **Priya Lakshmi** (staff). | "Staff log in with one tap. They only see their own leads plus the shared inbox." |
| 0:30 | Wait for the **website enquiry toast + chime**. Sidebar *Inbox* badge goes up. Open **Inbox**. | "A website enquiry just arrived. It cannot sit unnoticed: sound, popup, badge, and a response timer." |
| 1:00 | Tap **Claim** on it. Open the lead. Point at the SLA badge (*Respond within 13m*). | "First reply is tracked. If nobody calls in 15 minutes it turns red; at 60 minutes the owner sees it escalated." |
| 1:30 | **N** (or *New Lead*) → paste: `Murugan 98421 12345 Hosur Road, 2 TVS label printer venum, budget 25000, urgent`. | "Staff paste a WhatsApp message, and it fills name, phone, product, quantity and budget. Tamil and Tanglish work too." |
| 2:00 | Paste the same number again. | "Duplicate phone is caught, so the same customer is never entered twice." |
| 2:15 | On a lead: **Call** (big green button) → **Log outcome**. Try saving without a next step. | "After every call the staff must set the next follow-up, or mark Won/Lost. No lead is ever left hanging." |
| 2:45 | **Follow-ups** page: Overdue / Today / Upcoming tabs, one-tap Call, WhatsApp (prefilled), Reschedule. | "This is the staff's daily to-do. Overdue is red." |
| 3:15 | On the lead, **AI assistant** panel: score with reasons, next step, best time to call, WhatsApp draft, recommended products. | "AI explains why a lead is hot and drafts the message. Today it is a demo engine; the real model plugs in behind a secure backend." |
| 3:45 | Top-right **user menu → Switch user → Owner**. Dashboard: AI briefing, untouched, overdue per staff, conversion, lost reasons, leaderboard, at-risk leads. | "The owner sees the whole shop in one screen, and who is behind." |
| 4:15 | **Team day** (owner): per-person calls, WhatsApps, visits, wins, and what rolls over to tomorrow. **Pipeline**: drag a card to *Lost*, so the reason is required. | "End-of-day report without asking anyone." |
| 4:30 | **AI Assistant** → ask *"Show hot leads"* then *"Priya overdue"*. | "Ask the CRM in plain words." |
| 4:45 | Toggle **EN → த** (top bar). Everything switches to Tamil. | "Staff can use it fully in Tamil." |

## Notes
- All data is local to the browser (mock API). *Settings → Reset demo data* restores the story: overdue, due-today, untouched and hot leads.
- Settings lets you turn the enquiry simulator and sound off, and change the response-time rules.
- Customers, Products and Reports pages are placeholders in this demo build.
